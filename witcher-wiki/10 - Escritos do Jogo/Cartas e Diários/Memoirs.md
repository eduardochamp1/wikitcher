# Memórias

> **Terceiro dos diários de Urskar, sobre a aliança entre dois clãs.**

| | |
|---|---|
| **Título original** | Memoirs |
| **Tipo** | Diário |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Conteúdo cortado; não aparece como item no jogo |

Um morador de Undvik conta que [[Crach an Craite]] convidou o jarl do clã Tordarroch para uma caçada. Muitos temeram uma armadilha, mas não houve traição. No banquete, Crach propôs fazer as pazes entre os clãs e selar a amizade com um ataque conjunto a [[Nilfgaard]].

## O que revela
- Os jarls abateram ursos, alces e caça menor durante a caçada.
- Clã an Craite e clã Tordarroch tinham uma rivalidade que Crach quis encerrar.
- O autor vê a aliança como boa para Undvik, diante dos tempos difíceis que se anunciam em [[Skellige]].
