# Carta de um salteador

> **Bilhete entre bandidos sobre uma torre assombrada e um bruxo.**

| | |
|---|---|
| **Título original** | Highwayman's letter |
| **Tipo** | Carta |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Conteúdo cortado; seria encontrada em Kaer Gelen |

Kvegg avisa Gunnar para não subir ao topo de uma torre e não bancar o herói. Ele pretende fazer um bruxo que anda pelas ilhas resolver o problema e, depois, pagá-lo com uma facada.

## O que revela
- Algo no alto da torre uiva durante a noite.
- Os bandidos planejam trair o bruxo em vez de pagar pelo serviço.
