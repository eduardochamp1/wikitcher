# Instruções de Ativação do Mecanismo

> **Manual de uso de um golem mecânico.**

| | |
|---|---|
| **Título original** | Mechanism Start-Up Information |
| **Tipo** | Guia |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Conteúdo cortado; não aparece como item no jogo |

O texto é um manual curto para operar a versão 3.70 de um golem. Explica que basta inserir uma ficha e dar o comando, lista o que verificar se a máquina não funcionar e indica a quem pedir reembolso.

## O que revela
- Reclamações e trocas ficam a cargo de um certo Munro Burch.
- Antes de reclamar, deve-se verificar se o coração do golem está carregado, se o módulo está instalado e se a ficha foi inserida.
- O manual proíbe retirar a trava de segurança, sob risco de ferimento grave ou morte.
