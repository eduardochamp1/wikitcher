# Poupança segura para tempos incertos

> **Folheto de propaganda de uma conta de poupança do banco Cianfanelli.**

| | |
|---|---|
| **Título original** | Sure Savings for Unsure Times |
| **Tipo** | Documento |
| **Jogo** | The Witcher 3: Blood and Wine |
| **Onde encontrar** | Dentro do banco Cianfanelli, em Beauclair, em geral durante a missão Paperchase |

O panfleto tenta atrair clientes preocupados com suas economias e com a guerra no Norte. Oferece uma conta chamada "Porcentagem Feliz", com rendimento garantido para depósitos a partir de três mil coroas, e remete os detalhes a um anexo de número 37.

## O que revela
- A guerra no Norte preocupava até os poupadores de [[Toussaint]].
- O depósito mínimo alto e as letras miúdas num anexo dão ao folheto um tom satírico.
