# Um código de duelo

> **Regulamento dos duelos entre nobres no ducado de Toussaint.**

| | |
|---|---|
| **Título original** | A Code Duello |
| **Tipo** | Guia |
| **Jogo** | The Witcher 3: Blood and Wine |
| **Onde encontrar** | Em estantes de casas de Toussaint, ou à venda com o Camerlengo Ducal |

O texto apresenta as regras que todo cavalheiro deve seguir num duelo em [[Toussaint]]. Embora seja um acordo de honra, quem o desrespeita fica malvisto e é excluído da boa sociedade. As regras vão da escolha dos padrinhos ao anúncio do vencedor.

## O que revela
- Cada lado tem direito a um padrinho, que zela pelo andamento correto do duelo.
- As partes combinam se a luta termina no primeiro sangue ou na rendição; duelos até a morte dão prisão imediata por ordem da duquesa ([[Anna Henrietta]]).
- Quem foi desafiado escolhe as armas, e o desafiante é obrigado a aceitar.
- Depois do duelo é proibido buscar qualquer reparação, inclusive vingança de sangue: o resultado encerra a disputa.
