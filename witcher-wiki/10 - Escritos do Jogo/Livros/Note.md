# Bilhete

> **Bilhetes curtos de bandidos sobre um saque escondido.**

| | |
|---|---|
| **Título original** | Note |
| **Tipo** | Documento |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Não informado |

O texto reúne versões diferentes de um bilhete. Uma é só uma pista, dizendo que um mastro torto marca o lugar de um tesouro. A outra é um recado de Jackme a Lulke, mandando esconder o saque junto com o resto, debaixo de uma cabana perto do moinho, para dividir depois.

## O que revela
- Jackme avisa que, pelo que se fala na estalagem, dois bruxos chegaram à cidade dispostos a trabalhar.
- Parte do material parece ser conteúdo cortado do jogo.
