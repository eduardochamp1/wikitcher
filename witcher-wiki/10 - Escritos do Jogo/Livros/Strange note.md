# Bilhete estranho

> **Bilhete provocador deixado num baú de bandidos.**

| | |
|---|---|
| **Título original** | Strange note |
| **Tipo** | Documento |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Conteúdo cortado; deveria estar num acampamento de bandidos entre o Campo de Refugiados e Midcopse |

Bilhete de uma linha só, com um insulto, avisando ao curioso que a curiosidade leva ao inferno. Pelo contexto, servia de isca numa emboscada de bandidos que acabou fora do jogo.

## O que revela
- O acampamento onde ficaria o bilhete teria uma mecânica de emboscada que não funciona no jogo.
