# O conto do velho urso

> **Conto infantil sobre um urso que semeia os campos de uma aldeia.**

| | |
|---|---|
| **Título original** | Tale of the Old Bear |
| **Tipo** | Livro |
| **Jogo** | The Witcher 3: Wild Hunt |
| **Onde encontrar** | Conteúdo cortado; o texto existe nos arquivos, mas nunca virou item |

Um velho urso procura mel numa árvore e encontra a colmeia vazia. Ele vai até a aldeia, assusta as crianças, arromba a despensa e sai andando sobre duas patas com um saco de sementes, que espalha pelos campos recém-colhidos. Na primavera seguinte, os campos se cobrem de flores, as abelhas voltam e há mel para todos, inclusive para o urso.

## O que revela
- É uma fábula simples, no estilo dos contos de ninar, sem ligação com personagens ou fatos históricos.
- A moral gira em torno de cuidar da natureza para colher os frutos depois.
