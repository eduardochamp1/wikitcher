# Calendário e Festas

O calendário nórdico usa os meses comuns e as **festas antigas élficas/druídicas**, que marcam a passagem das estações:

| Festa | Época | Notas |
|---|---|---|
| **Imbaelk** | início de fevereiro | Festa do despertar |
| **Birke** | equinócio de primavera | |
| **Belleteyn** | 1º de maio | Noite da fertilidade; aniversário de [[Ciri]] |
| **Midaete** (Solstício) | solstício de verão | |
| **Lammas** | 1º de agosto | Colheita |
| **Velen** (Equinócio de outono) | setembro | Noite da Caçada Selvagem nos livros |
| **Saovine** | 31 de outubro / 1º de novembro | Noite dos mortos |
| **Midinváerne** | solstício de inverno | |

Os nilfgaardianos usam um calendário próprio, contado a partir de eventos imperiais.
